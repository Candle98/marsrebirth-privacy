MARS REBIRTH / CANDLESTUDIO

隐私政策

Android 0.1.2 试玩版 · 更新及生效日期 2026年11月11日

一、适用范围
本政策说明 CandleStudio 在提供 MarsRebirth 游戏时如何处理信息。请在开始游戏前阅读。TapTap 客户端、TapPlay 运行环境和本政策网页的托管服务由各自服务商提供，其独立处理活动适用各自政策。

二、游戏本体处理的信息
游戏本体不要求注册账号，不提供聊天、广告、内购或联网对战，不集成广告、统计分析、TapTap 登录或防沉迷 SDK。基地进度、建筑、资源及设置保存在设备上的应用专用空间，用于继续游戏和恢复设置。游戏没有向 CandleStudio 服务器上传存档或行为统计的功能。
运行引擎会在设备上处理图形、音频、输入与系统兼容性信息，以运行游戏。发行包关闭公开日志和 Android 文件服务器。系统或 TapPlay 自身的运行与故障记录由对应服务商管理。
游戏不读取联系人、相册、麦克风、摄像头、精确位置或短信，也不要求这些敏感权限。

三、权限用途
Android 包声明网络访问、网络与 Wi-Fi 状态、保持唤醒、音频设置和振动权限，用于引擎网络状态检查、运行期间显示与音频管理、输入反馈等基础能力。声明权限不表示我们上传个人信息。游戏不自行请求共享存储读写权限，存档保存在应用专用空间。
点击“在线政策”会在浏览器打开公开政策页面。浏览器和托管服务为传输页面可能处理 IP 地址、浏览器信息与访问日志；此页面不添加广告、追踪脚本、表单或分析 Cookie。

四、TapTap 与 TapPlay
通过 TapPlay 游玩时，TapTap／TapPlay 可为账号、实名认证、防沉迷、运行安全及平台功能处理相关信息，由平台提供告知和授权流程。请阅读 TapTap 隐私政策：https://www.taptap.cn/doc/privacy-policy/
本游戏不通过 SDK 接收您的姓名、身份证号码、手机号或 TapTap 账号信息。游戏本体的存档机制为本地保存；如果您启用平台提供的存档备份功能，其处理方式和删除入口以平台说明为准。

五、主动联系我们
如果您发送邮件反馈问题，我们会收到您的邮箱地址、邮件内容及您主动提供的附件，仅用于回复、排查和处理请求。请勿发送身份证、密码或与问题无关的个人信息。邮件由邮箱服务商处理；我们在问题处理所需期间保留相关记录，之后删除或匿名化，法律另有要求的除外。

六、存储、共享与保护
游戏存档在您的设备上持续保留，直至您重新开始游戏、清除应用数据或卸载应用。重新开始会替换原进度。TapPlay 环境内的清理与备份需同时按平台入口操作。CandleStudio 不出售个人信息，不通过游戏向第三方共享存档，不建立游戏账号数据库，也不主动将游戏存档传输至境外。公开政策页面可能由境外托管节点提供。
我们采取必要的访问控制和最小化处理措施保护主动反馈的信息，但网络和设备环境无法保证绝对安全。

七、您的选择与权利
您可以通过游戏设置及系统设置管理游戏数据和权限，通过清除应用数据或卸载删除本地记录。游戏无独立账号，因此无需办理游戏账号注销。对反馈邮件涉及的信息，您可通过联系邮箱请求访问、更正、复制、删除或撤回相关授权；我们会在核实请求后依法处理。TapTap 账号、实名认证或平台备份的权利请求请通过 TapTap 提供的入口办理。

八、未成年人
未成年人应在监护人指导下阅读本政策并使用游戏，不满十四周岁的用户应取得监护人同意。TapPlay 的实名和防沉迷要求由平台执行，本游戏不提供绕过入口。监护人发现孩子向我们提供了不必要的信息时，可联系我们处理。

九、更新与联系
功能或信息处理方式发生变化时，我们会更新本政策及生效日期；涉及新增个人信息处理的，将按要求另行告知并征得必要同意。
